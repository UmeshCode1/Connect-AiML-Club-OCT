# Certificate Generation Worker

## Purpose
Idempotent batch generation engine for verified credentials.

## Responsibilities (Future Phase 7)
- Template layout rendering
- Dynamic text replacement (Recipient, Event, Date, Certificate ID)
- Cryptographic verification token generation
- Verification QR code insertion
- PDF rendering and Google Drive upload
- Idempotency guarantees to prevent accidental duplicate credentials

Architecture initialized. Awaiting Phase 7 activation.
