# Data Sync Worker

## Purpose
Background synchronization worker for Tally and Google Sheets workflows.

## Responsibilities (Future Phase 3)
- Ingest registration submissions from Tally
- Synchronize club roster spreadsheets from Google Sheets
- Normalize incoming fields against canonical StudentProfile schema
- Populate staging tables and detect conflicts
- Track sync run metrics (records seen, created, updated, failed)
