# Media Worker

## Purpose
Background asynchronous job processor for event media assets (photos, videos, posters).

## Responsibilities (Future Phase 5)
- Google Drive file metadata ingestion
- Image thumbnail generation
- Video keyframe extraction
- Job state tracking (`QUEUED -> PROCESSING -> PROCESSED / FAILED`)
- Duplicate detection via checksums

## Current State
Architecture initialized. Awaiting Phase 5 activation.
